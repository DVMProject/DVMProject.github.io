About DVMProject

DVMProject is an open-source suite of software tools and hardware dedicated to advancing digital radio technology. The project includes various modules, such as a network core, air interface, and a range of management tools that can be used to build a versatile digital radio network. It supports multiple topologies and can be customized to suit your needs.

Key Features

  • Accessible: Low-cost hardware lowers the barrier to entry.
  • Community-Driven: Built through contributions from a global userbase.
  • Broad Hardware Support: Compatible with multiple platforms and devices.
  • Multimodal: P25, DMR, and NXDN.
